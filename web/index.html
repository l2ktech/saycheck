SayCheck 机器人语音调试台
未加载套件 传感器未就绪 本地存储 —

把手机架在机器人前面，就能测它的语音。

不需要接 SDK、不改固件、不逆向协议。SayCheck 自动播放一组测试语句， 用麦克风听声音、用摄像头看动作，最后给你一张成功率排行。 判定用确定性的信号，不用 AI。

1 · 测试套件

—

套件是一份 JSON（schema/suite.schema.json）。任何脚本生成的文件都能直接丢进来。

2 · 测试哪几组

不选＝全部。全部 0 条；当前选中 0 条。

3 · 参数

默认值来自真机实测：-34 dBFS 约等于线性 RMS 0.02，帧差 3 对应「静止 <1、动起来 >3」。 播完先静置是为了不把音频尾音当成机器人应答。
